# Chinois sans frontière

**Chinois sans frontière** is a mobile migration of the textook "Chinois sans frontière". It provides a easy to hack demo with Tome I's Lessons 1 to 8, a core graphic guideline. Functions of `Convert` between chinese systems, `Play audio`, `Play character's writing` are expected. Covered contends include `dialogues`, `vocabulaire`, `compréhension orale`, `prononciation` sections.

No account necessary.
We would welcome a modular account management, so an user could keep his creations and liked documents under hand. See section "Contributing".

## Stack
- HTML/CSS: Bulma.css
- JS: native javascript
